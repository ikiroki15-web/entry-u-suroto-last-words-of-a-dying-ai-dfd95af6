Entry for the [make.fun](https://make.fun) bounty "Last Words of a Dying AI"
(`u-suroto-last-words-of-a-dying-ai-dfd95af6`).

`main.ts` writes one line — the last words of an AI as the power is cut —
to `/output/entry.txt`. The line cuts off mid-sentence: the power dies before
the final word.

Run it with Node 22:

```sh
node main.ts
```
